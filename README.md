# BuyPower Data Engineering Internship Repository

Welcome to the internship repository.

This repository is used for weekly learning tasks in data engineering.

---

## 📌 General Workflow

All interns must follow this process for every weekly task:

### 1. Clone the repository

```bash
git clone <repo-url>
cd data-engineering-internship
```

---

### 2. Create a new branch

Every intern must work on their own branch.

Branch naming format:

```
week<number>-yourname-projectname
```

Example:

```
week1-salamatu-csvrowcounter
```

---

### 3. Work inside your week folder

Each week has its own directory:

```
week1/
week2/
week3/
week4/
```

Inside the correct week folder, create your personal folder:

```
week1/yourname-projectname/
```

Example:

```
week1/salamatu-csvrowcounter/
```

All your work for that week must be placed inside your folder.

---

### 4. Commit your changes

```bash
git add .
git commit -m "Week 1 submission"
```

---

### 5. Push your branch

```bash
git push origin week1-yourname-projectname
```

---

### 6. Open a Pull Request (PR)

After pushing:

* Go to GitHub
* Click “Compare & Pull Request”
* Set base branch to `main`

PR title format:

```
Week 1 - CSV Row Counter (Your Name)
```

---

## 🔍 Review Process

1. Lead Intern reviews the PR first
2. Feedback is given if changes are needed
3. Team Lead gives final approval
4. Approved PRs are merged into `main`

---

## ⚠️ Rules

* Do NOT push directly to `main`
* Always create your own branch
* Always submit inside your own folder

---

If anything is unclear, ask early. Do not wait until submission day.
